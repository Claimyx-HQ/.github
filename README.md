# Claimyx-HQ/.github

Organization-wide default community health files. GitHub uses the files in this repository for every
Claimyx-HQ repository that does not have its own version.

- `pull_request_template.md` - the default pull-request template, including the security check that the
  Application Security Policy (Section 10) requires before a reviewer approves a pull request.

To change the template for one repository only, add `.github/pull_request_template.md` to that repository.
